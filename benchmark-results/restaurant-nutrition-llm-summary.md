## 판단

- 기존 브랜드에서는 하이브리드 RAG가 가장 정확하다. 열량 MAE 48.72kcal로 동일 표본의 문자 유사도 기준선 57.43kcal보다도 좋다.
- 미관측 브랜드에서는 RAG 전체 적용이 순수 LLM과 문자 유사도 기준선보다 나쁘다. 부정확한 검색 근거가 LLM을 잘못 유도한다.
- 다만 미관측 브랜드 RAG도 confidence ≥ 0.7로 보류하면 MAE 83.67kcal까지 낮아진다. 이때 커버리지는 44%다.
- 운영 후보는 기존 브랜드에는 RAG, 미관측 브랜드에는 순수 LLM 또는 confidence 기반 선택적 RAG를 적용하는 분기형 프로토콜이다.
- 탄수화물·지방 정답 표본은 14~32개로 작아 추가 정답 데이터 없이는 방식 간 우열을 확정하지 않는다.
- 순수 LLM 한 배치가 숫자 대신 null을 반환해 기존 브랜드 10개가 실패했다. 숫자 유효성 검증과 재시도 규칙이 필요하다.
